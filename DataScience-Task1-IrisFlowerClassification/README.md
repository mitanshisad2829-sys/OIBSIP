# Iris Flower Classification 🌸

## 📌 Project Overview
This project is part of the Oasis Infobyte Data Science Internship.

The objective of this project is to classify Iris flowers into three species:
- Setosa
- Versicolor
- Virginica

using Machine Learning algorithms based on their physical measurements.

---

## 📂 Dataset
The Iris dataset is provided by Scikit-learn and contains 150 samples with the following features:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

Target Classes:
- Setosa
- Versicolor
- Virginica

## 🤖 Machine Learning Models

The following classification algorithms were used:

- K-Nearest Neighbors (KNN)
- Logistic Regression

---

## 📈 Model Performance

| Model | Accuracy |
|--------|----------|
| KNN | 100% |
| Logistic Regression | 100% |

Both models achieved perfect accuracy on the test dataset.

---

## 📌 Conclusion

The Iris Flower Classification model successfully classified all flower species with an accuracy of 100%. Both KNN and Logistic Regression performed equally well on this dataset.
