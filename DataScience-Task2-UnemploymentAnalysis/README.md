# Unemployment Analysis with Python

## OASIS INFOBYTE Data Science Internship - Task 2

### 📌 Project Overview

This project is a part of the OASIS INFOBYTE Data Science Internship. The objective is to analyze unemployment trends in India using Python. The project includes data cleaning, exploratory data analysis (EDA), and visualization techniques to understand unemployment patterns across different regions and time periods, with a special focus on the impact of the COVID-19 pandemic.

---

## 🎯 Objective

The main objectives of this project are:

- Load and explore the unemployment dataset.
- Clean and preprocess the data.
- Handle missing values.
- Convert the date column into datetime format.
- Analyze unemployment rates across different regions.
- Study monthly unemployment trends.
- Compare unemployment trends for selected states.
- Identify the top 10 states with the highest average unemployment.
- Analyze correlations among employment-related features.
- Compare unemployment before and after the COVID-19 outbreak.
- Draw meaningful conclusions using data visualization.

## 📂 Dataset

**Dataset Used:** Unemployment in India Dataset

The dataset contains information about unemployment rates, estimated employed population, labour participation rates, regions, and dates across different states of India.

---

## 📊 Project Workflow

### 1. Data Loading
- Imported all required libraries.
- Loaded the dataset using Pandas.

### 2. Data Exploration
- Displayed the first few rows.
- Checked dataset shape.
- Viewed column names.
- Examined data types.
- Generated summary statistics.

### 3. Data Cleaning
- Removed extra spaces from column names.
- Checked for missing values.
- Removed rows containing missing values.
- Converted the Date column into datetime format.

### 4. Exploratory Data Analysis (EDA)
- Region-wise average unemployment analysis.
- Monthly unemployment trend analysis.
- Time-series comparison of Maharashtra, Rajasthan, and Uttar Pradesh.
- Top 10 states with the highest average unemployment.
- Correlation heatmap.
- Pre-COVID vs Post-COVID unemployment comparison.

- Average Unemployment Rate by Region

- Unemployment Rate Over Time for Selected States
- Top 10 States with Highest Average Unemployment
- Correlation Heatmap
- Pre-COVID vs Post-COVID Comparison

---

## 📌 Key Findings

- Unemployment rates vary significantly across different states and regions of India.
- A noticeable increase in unemployment was observed during the COVID-19 pandemic.
- Some states experienced much higher unemployment rates than others.
- Correlation analysis helped understand the relationship between unemployment rate, employment, and labour participation rate.
- Data visualization makes it easier to identify patterns and trends in unemployment.
